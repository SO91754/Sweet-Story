SWEET STORY LANAKEN

STARTEN
1. Open deze map in VS Code.
2. Open Terminal.
3. npm install
4. Start met een eigen adminwachtwoord:

Mac / Linux:
ADMIN_PASSWORD='jouw-sterke-wachtwoord' npm start

Daarna:
Website: http://localhost:3000
Admin login: http://localhost:3000/login.html

BELANGRIJK
De standaardcode gebruikt ChangeMe-2026! alleen als je geen ADMIN_PASSWORD instelt.
Gebruik voor echt gebruik altijd een eigen sterk wachtwoord.

ADMIN KAN:
- nieuwe creaties toevoegen
- foto vanaf computer uploaden
- titel, categorie en beschrijving toevoegen
- bestaande creaties bewerken
- creaties verwijderen

DATA
data/works.json = alle portfolio-items
public/images/uploads/ = foto's die via admin worden toegevoegd

De eerste portfolio-afbeeldingen zijn uit de door jou aangeleverde Instagram-screenshots geknipt.
Voor publicatie is het beter om later de originele hoge-resolutie foto's te gebruiken.
